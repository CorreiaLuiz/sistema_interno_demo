## Perguntar ao assistente

1. Clique no botão **"Dúvidas?"** (o robozinho), no canto de baixo à direita de qualquer tela.
2. Escreva a pergunta com as suas palavras (ex.: "como mando a guia para o cliente?") e aperte **Enter**.
3. A resposta vem com o passo a passo e, embaixo, o link **"Ver passo a passo"** com as imagens do manual.
4. Diga se ajudou (👍 ou 👎). Com 👎, a pergunta vai para o administrador ensinar a resposta certa.

![Assistente de dúvidas](e-assistente.png)

> **Dica:** o assistente conhece o manual, mas não vê os dados do sistema (empresas, guias, tarefas). Para dados, ele diz em qual tela olhar.

## Usar o manual

No menu, **"Ajuda"** abre o manual:

1. A primeira tela mostra as **perguntas frequentes** e os assuntos em cartões, separados por área.
2. Clique num cartão para abrir o assunto. No alto, **"Neste assunto"** leva direto a cada parte.
3. No fim do assunto, **"Anterior"** e **"Próximo"** passam para os outros assuntos.
4. Para procurar uma palavra em todo o manual, use **"Buscar no manual"**, à esquerda.
5. Clique numa imagem para ver maior.

![Manual](e-ajuda-manual.png)

## Ensinar respostas ao assistente (administrador)

O assistente **aprende com as perguntas**: o administrador ensina a resposta certa e, quando alguém perguntar algo parecido, o assistente responde com ela. Funciona mesmo sem a IA ligada.

1. Na tela **Ajuda**, abra a aba **"Perguntas feitas"**.
2. Marque **"Só as que precisam de resposta"**: aparecem as perguntas em que a pessoa clicou 👎 ou que o manual não respondeu.
3. Clique em **"Ensinar resposta"**, escreva a resposta certa e clique em **"Salvar na memória"**.
   - Na pergunta, dá para escrever mais de um jeito de perguntar, um por linha.
   - Escolha também o passo a passo do manual que acompanha a resposta, se houver.
4. Para ensinar algo que ninguém perguntou ainda, use a aba **"Memória do assistente"** → **"+ Ensinar uma resposta"**.

![Ensinar uma resposta](e-ajuda-ensinar.png)

As respostas ensinadas aparecem também como **perguntas frequentes** no início do manual. Na aba **"Memória do assistente"** dá para editar ou excluir cada uma e ver quantas vezes foi usada.

> Escolha **"Clientes"** em **Para quem** quando a resposta for para a Área do Cliente: os clientes só recebem respostas marcadas para eles.
