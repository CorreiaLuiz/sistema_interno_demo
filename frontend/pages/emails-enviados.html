E-mails enviados

O sistema ainda não está na internet. Os e-mails saem normalmente, mas o controle de abertura e de download pelo e-mail só começa a funcionar quando o sistema estiver online (o celular do cliente precisa conseguir acessar o sistema). Downloads pela Área do Cliente já são registrados.
Como o sistema sabe se o cliente abriu ou baixou?
  • Abriu o e-mail: o e-mail leva uma imagem invisível; quando o cliente abre, ela carrega e o sistema anota. É uma indicação, não 100%: o Outlook pode bloquear imagens (aí não aparece como aberto) e o iPhone às vezes carrega sozinho.
  • Baixou pelo e-mail: quando o cliente clica em "Baixar a guia" dentro do e-mail.
  • Baixou pela Área do Cliente: quando baixa a guia no portal, com login.
  • O anexo não avisa: se o cliente abrir o PDF anexado direto no e-mail, não tem como o sistema saber.
  • Cada pessoa recebe o seu próprio e-mail, por isso dá para ver quem abriu.
